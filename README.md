# Carbon Footprint Calculator

A responsive school web-development project built with HTML, CSS, and Bootstrap 5.

## Files
- `index.html` — page structure, Bootstrap layout, and simple working footprint estimate
- `style.css` — custom colours, spacing, and responsive styling

## Run locally
Open `index.html` in a web browser. An internet connection is needed to load Bootstrap and the sample environmental image.

## Publish with GitHub Pages
1. Create a **public** repository on GitHub named `carbon-footprint-calculator`.
2. Upload `index.html`, `style.css`, and `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/ (root)**, then click **Save**.
6. Wait for deployment, then open the URL shown on the Pages settings screen.

The live URL normally looks like `https://YOUR-USERNAME.github.io/carbon-footprint-calculator/`.
